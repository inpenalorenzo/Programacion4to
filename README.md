# 🐍 Programación IV - Introducción a Python y Desarrollo de Videojuegos

Bienvenido al repositorio de la materia **Programación de 4to Año**. Este espacio está dedicado a documentar el aprendizaje del lenguaje Python, desde sus bases fundamentales hasta la creación de un proyecto final integrador: un videojuego.

## 🎯 Objetivos de la Materia
* Dominar la sintaxis básica y lógica de programación en Python.
* Implementar estructuras de datos complejas para la gestión de información.
* Aplicar conceptos de programación orientada a objetos en un entorno lúdico.
* Desarrollar un videojuego funcional aplicando buenas prácticas de código.

## 📚 Contenidos del Curso

### Fase 1: Fundamentos de Python
* **Introducción:** Instalación del entorno, uso de la terminal y primer "Hola Mundo".
* **Variables y Tipos:** Manejo de strings, enteros, flotantes y booleanos.
* **Estructuras de Control:** 
  * Condicionales (`if`, `elif`, `else`).
  * Bucles (`for`, `while`).
* **Funciones:** Definición, parámetros y retorno de valores.

### Fase 2: Estructuras de Datos
* **Listas y Tuplas:** Manipulación, métodos y ordenamiento.
* **Diccionarios:** Almacenamiento clave-valor, anidamiento y casos de uso.

### Fase 3: Proyecto Videojuego 🎮
* **Lógica del Juego:** Game loop, manejo de eventos y colisiones.
* **Interfaz:** Renderizado de gráficos básicos y controles de usuario.
* **Integración:** Uso de diccionarios para gestionar inventarios, puntajes y estados del juego.

## 🛠️ Requisitos
Para trabajar en este curso, necesitarás:
1. **Python 3.10+**
2. **Visual Studio Code** (o tu IDE preferido)
3. Librería **Pygame** (se instalará en la fase 3)

## 🚀 Cómo usar este repositorio
Cada carpeta corresponde a una unidad temática. Puedes ejecutar los ejemplos directamente con:
```bash
python nombre_del_archivo.py
```
